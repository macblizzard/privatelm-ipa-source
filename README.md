# privatelm-ipa-source

Unsigned PrivateLM IPAs (built by GitHub Actions in macblizzard/cross-platform-llm-client) and an AltStore-format source usable in FlareStore, SideStore, Feather, ESign, etc.

Add this source URL in FlareStore (Repositories > Add):

https://raw.githubusercontent.com/macblizzard/privatelm-ipa-source/main/apps.json

IPAs are on the Releases page. They're unsigned, so FlareStore signs them with your certificate on install.
